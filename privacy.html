Privacy Policy

Shorts Publisher · Last updated November 6, 2026

Shorts Publisher is a personal tool, run on its owner's computer, that uploads the owner's own videos to the owner's own social media accounts. This policy explains what data the tool accesses, how it is used and stored, and how to remove it.

Data the tool accesses

When an account is connected, the tool asks the platform for permission to:

  • YouTube (Google): upload videos to the connected channel, and read the channel's basic information (channel name and ID) and the status of videos it uploaded.
  • TikTok: upload videos or drafts to the connected account, and read basic profile information (display name).
  • Instagram and Facebook (Meta): publish videos to the connected Instagram professional account and Facebook Page, and read their basic information (name and ID).

The tool does not access private messages, contacts, comments, viewer data, payment data or any other personal information.

How the data is used

The data is used only to publish the owner's videos and to confirm that each upload worked. It is not used for advertising, analytics, profiling, or to train AI models.

Storage

  • Login tokens issued by each platform are stored only on the owner's computer, in a file that is never shared or uploaded anywhere.
  • A local log keeps the ID, link and title of each video the tool uploaded.
  • The tool has no server of its own. It sends data only to the official APIs of YouTube, TikTok and Meta.

Sharing

Data obtained through the tool is not sold, rented or shared with anyone.

Google API Services

Shorts Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Shorts Publisher uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access and deleting data

  • Google / YouTube: revoke access at any time on the Google security settings page.
  • TikTok: Settings and privacy → Security → Manage app permissions.
  • Meta: Settings → Apps and websites (Facebook), or Business Integrations.

Once access is revoked, the stored token stops working, and the owner deletes the local token file. Stored data is kept only until access is revoked or the tool is no longer used.

Cookies

Neither the tool nor this website uses cookies or tracking.

Changes and contact
